# Projeto-06-Ensinando-com-as-Tartarugas
 Utilizando conceitos de programação para criar soluções, resolver desafios e explorar a lógica computacional. Cada atividade contém seu respectivo código-fonte, permitindo que os alunos visualizem, copiem e estudem as soluções, desenvolvendo seus conhecimentos em programação de maneira prática e educativa.
